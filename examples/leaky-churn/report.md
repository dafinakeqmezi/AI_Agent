# Predicting Customer Churn with Machine Learning

## Abstract

We build an accurate model to predict customer churn. Our model outperforms existing approaches.

## Introduction

Customer churn is costly for telecom companies. The goal is to build an accurate model.

## Data

We use a churn dataset with customer features and a binary churn label.

## Method

We compare a Random Forest with an LSTM network. Models were evaluated with 5-fold cross-validation.

## Results

The Random Forest reaches an accuracy of 99.2% on the test set, while the LSTM reaches 97.5%.

## Conclusion

Random Forest is the best model for churn prediction.
