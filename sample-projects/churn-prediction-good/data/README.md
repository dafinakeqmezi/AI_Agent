# Dataset card: `customer_churn.csv`

| | |
|---|---|
| Source | Synthetic. Generated by `src/make_dataset.py` (seed 42). No real customer data is used. |
| License | CC0 1.0 (public domain). The generator script is part of this project. |
| Rows | 1,200 customers (one row per customer, unique `customer_id`) |
| Target | `churn`: 1 = customer left within the observation period, 0 = stayed |
| Class distribution | 317 churners (26.4%) / 883 non-churners (73.6%): moderately imbalanced |
| Missing values | `monthly_charges`: 24 rows (2.0%), missing completely at random by construction |
| Duplicates | none (checked in `src/preprocess.py::load_data`) |

## Columns

| Column | Type | Description |
|---|---|---|
| `customer_id` | string | Identifier. Dropped before modelling. |
| `age` | int | Customer age in years (18-79) |
| `tenure_months` | int | Months since the customer joined (1-72) |
| `contract_type` | category | `month-to-month`, `one-year`, `two-year` |
| `internet_service` | category | `dsl`, `fiber`, `none` |
| `payment_method` | category | `electronic-check`, `credit-card`, `bank-transfer`, `mailed-check` |
| `monthly_charges` | float | Monthly bill in EUR (18-120) |
| `support_calls` | int | Number of support calls in the last 6 months |
| `churn` | int (0/1) | Target |

## Generating process

Churn is drawn from a logistic model whose log-odds increase with month-to-month
contracts, short tenure, high monthly charges, electronic-check payment and four
or more support calls. The support-call effect is stronger for month-to-month
customers (an interaction). See `src/make_dataset.py` for the exact
coefficients. All features are measured before the churn outcome, so none of
them encodes the target.

## Reproducing the file

```
python src/make_dataset.py
```
